# Epic-game · «Портальная станция 37-C»

Один готовый файл для Roblox Studio: **`RickAndMorty_Portals.rbxlx`** (≈10 МБ).
Открывается как обычный проект Roblox Studio — без плагинов, без внешних ассетов,
все звуки и текстуры частиц берутся из встроенных `rbxasset://` файлов.

## Что внутри

**Персонажи (все — управляемые процедурной анимацией, реагируют на ProximityPrompt и клик):**

| Персонаж | Где стоит | Порталы |
|---|---|---|
| **Rick Prime** | площадь, сцена в центре | 🟢 **зелёные** |
| **Evil Morty** | площадь, подиум, руки за спиной | 🟡 **жёлтые** |
| Рик C-137 + Морти | площадь, у входа | зелёные |
| Совет Риков (12 шт.) | Цитадель, зал Совета | — |
| Стража | Цитадель | — |

**Портальная пушка** — два варианта: модель в руках у NPC и полноценный `Tool` в StarterPack
у игрока (ЛКМ — зелёный портал Рика Прайма, ПКМ — жёлтый портал Злого Морти).

**Анимация выстрела**: зарядка ствола (растущее свечение + нарастающий гул), вспышка
дула, трассер, ударная волна, имплозия, разворот портала, тряска камеры, отдача
(`GripPos` + kick камеры), вспышка экрана и звук.

**Локация** — 4 зоны, связанные порталами:

1. **Площадь 37-C** — центральный нексус, кольца, стела, 4 портальные бури, постамент
   с голограммой, скамейки, неон.
2. **Мад Макс** (`x ≈ -380`) — пустошь: дюны, руины, остовы машин, черепа-скалы, лава.
3. **Алиен-мир** (`x ≈ +380`) — фиолетовая почва, светящиеся споры, «живая река», флора.
4. **Цитадель Риков** (`z ≈ -380`) — купол, зал Совета с огромным столом, 12 делегатов,
   позолоченная статуя Рика.

Плюс **подземная лаборатория Рика** под площадью (пандус-траншея, верстак, колба с
портальной жидкостью, летающая тарелка, аркада, диван, огурчик-Рик в банке) и парящие
острова в небе.

## Как играть

- Спавн — на площади, лицом к порталам.
- Пройди в портал у постамента → окажешься в другой зоне (все статичные порталы связаны
  парами через `LinkTo`).
- Возьми **Portal Gun** из рюкзака: ЛКМ открывает зелёный портал, ПКМ — жёлтый; войди в
  один — выйдешь из другого. Портал нельзя поставить ближе 7 стюдов к себе.
- Клик по NPC или клавиша **E** рядом — реплика; клик по Рику Прайму или Злому Морти
  заставляет их открыть свой портал.

## Сборка из исходников

Файл `.rbxlx` генерируется скриптами на Node: `tools/` — геометрия, `src/` — Lua-код.

```bash
npm install                                   # rbx-dom (сборка XML) + stylua (проверка Lua)
node tools/build.js                           # → RickAndMorty_Portals.rbxlx
```

Скрипт сам проверяет корректность и делает round-trip:

```
Сборка мира…
  деталей в мире: 6068
  имена классов и свойств проверены
Генерация XML…
  записано: …/RickAndMorty_Portals.rbxlx 9.81 МБ
Проверка: инстансов 9266 · повторная кодировка 9.81 МБ — OK
Сервисы: Workspace, Lighting, ReplicatedStorage, ServerScriptService, StarterPlayer, …
```

## Проверки

| Скрипт | Что проверяет |
|---|---|
| `node tools/build.js` | сборка + сверка всех классов и свойств с базой рефлексии Roblox |
| `node tools/inspect.js` | разбор готового файла: классы, группы, порталы, скрипты, Tool |
| `node tools/check_world.js` | пол под ключевыми точками, группы анимации, «висящая» геометрия |
| `node tools/check_portals.js` | у каждого портала нормаль, точка выхода и пол под ней |
| `node tools/check_path.js` | профиль маршрута: перепады высоты и обрывы |
| `node tools/check_lua_api.js` | все `Enum.*.*` в Lua против базы Roblox |
| `node tools/render_map.js` | оффлайн-рендер мира в PNG (карта и изометрия площади) |
| `npx stylua --check src/` | синтаксис и форматирование Lua |
