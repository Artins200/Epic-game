# Epic-game — «ТИХИЙ ШТОРМ»

Шутер от первого лица на three.js (без сборки, запускается прямо из браузера).
Операция по зачистке вражеской базы в три главы.

## Запуск

```bash
python3 -m http.server 8123 --bind 0.0.0.0
# открыть http://localhost:8123
```

Любой статический сервер подойдёт — сборки не требуется.

## Управление

| Клавиша | Действие |
|---|---|
| `W A S D` | движение |
| `Мышь` / `ЛКМ` | обзор / огонь |
| `R` | перезарядка |
| `SHIFT` | бег |
| `E` | взаимодействие |
| `SPACE` | прыжок (в заставке — пропуск) |
| `ESC` | пауза |
| `F` | озвучка вкл/выкл (субтитры остаются всегда) |

## Что происходит в игре

**Глава 1 — «Тихий шторм» (заставка).** Полёт на борту, командир ставит задачу
(«зачищай там всё это дело»), камера показывает нашего бойца, командир решает,
что «это будет легко». Дальше прыжок с парашютом — и уже в воздухе выясняется,
что оружие осталось на борту: сбрасывают ящик со стволом.

**Глава 2 — «Квадрат 7» (база).** Портала на следующую локацию в начале нет.
Сначала нужно дойти до центрального здания и выйти на связь через аппаратуру —
там скажут, что уходить ещё рано и что скоро десантируется подмога
(она действительно высаживается после 6-й волны). Затем 9 волн зачистки.

После 9-й волны — **великая паника**: в эфире базы слышен приказ «забыть про нас
и эвакуироваться, пока есть возможность». Большая часть солдат бежит к проёмам
периметра, часть поднимает руки, часть падает и просит пощады, а некоторые
дерутся до последнего.

**Волна 10** — продержаться 2 минуты до борта. Дальше катсцена: прилетает
самолёт, командир говорит, что мы «охренеть как хорошо справились», и отправляет
в подвал штаба за секретными данными.

**Глава 3 — «Подвал» (короткая).** Отдельная локация: лестница вниз, узкие
проходы, серверная, архив и лаборатория. Нужно вынести три технологии, отбиться
от охраны и уйти через шахту эвакуации.

## Структура

```
index.html            экран, HUD, меню
css/style.css         интерфейс
js/main.js            точка входа
js/game.js            состояния, волны, паника, эвакуация, подвал
js/core/              игрок, ИИ солдат, звук, голос, эффекты, ввод, HUD
js/world/base.js      база «Квадрат 7»
js/world/basement.js  подвал (лестницы, узкие проходы)
js/scenes/intro.js    заставка с десантом
js/scenes/cutscene.js таймлайны, камера, модели техники
vendor/               three.js (локально, без CDN)
```

Звук синтезируется на WebAudio, озвучка реплик — через `speechSynthesis`
(русский голос системы); если его нет, работают субтитры.
